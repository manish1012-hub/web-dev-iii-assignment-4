# PulseChat — Real-Time Chat Application

Built on the Express + Socket.IO backend from class with a responsive frontend and personal/multi-user room support.

## Features
- **Preserved Class Backend Events**: `gyankibaat`, `join`, `kuchbhi`, `announcement`, and live `count`.
- **Personal & Public Rooms**: Create private personal rooms (joinable via Room ID) or public group rooms.
- **Multi-User Sync**: Real-time messaging, live room member lists, online user count, typing indicators, and emoji picker.

## How to Run in VS Code
1. Open the `chatapp` folder in **VS Code**.
2. Open the VS Code Terminal (`Ctrl + ~` or `Cmd + J`).
3. Run:
   ```bash
   npm install
   npm start
   ```
4. Open [http://localhost:8080](http://localhost:8080) in multiple browser tabs to test multi-user chat and personal rooms.
